# Руководство Videron

[English](guide.md) · **Русский**

Videron — локальное настольное приложение для пространственных заметок. Первый запуск открывает пустой холст. Кнопка **Посмотреть пример** открывает отдельное пространство с готовыми заметками и рисунком. Переключатель в левом верхнем углу возвращает в личное пространство.

## Запуск в Windows

При сборке из исходников для Windows приложение появится в `build/bin/Videron.exe`. [Сборка приложения](../README.ru.md#сборка-приложения) Чтобы перейти на другую версию, закройте открытый Videron и запустите её EXE-файл. Окну приложения нужен Microsoft Edge WebView2 Runtime. Сборка включает редактор, шрифтовые стили, холст, поиск и встроенное расширение. Для работы с заметками подключение к интернету не требуется.

Интерфейс доступен на русском и английском. Выберите **Русский** или **English** в поле **Язык / Language** внизу боковой панели. Язык меняется сразу и запоминается на этом устройстве. При первом запуске выбран русский.

Для белого холста и светлых редакторов выберите **Настройки → Тема оформления → Светлая**. Вернуться к тёмной теме можно там же. Выбор сохраняется на этом устройстве для всех пространств.

## Области и заметки

В боковой панели заметки находятся внутри своих областей. На верхнем уровне также видны заметки без области. Стрелка у названия сворачивает ветку, щелчок по заметке открывает её. С клавиатуры перемещайтесь по дереву стрелками и открывайте выбранную заметку клавишей **Enter**.

## Заметки с данными

Кнопка **Данные** создаёт заметку с редактором строк. Можно сразу печатать, вставить текст из буфера или выбрать **Вставить файл…**. При вставке в пустую заметку расширение файла подсказывает редактору формат. Среди доступных форматов есть JSON, JSON Lines, CSV, TSV, JavaScript, TypeScript, Python и SQL.

Меню **Строки** применяет команду к выделенным строкам, а при пустом выделении ко всему документу. Доступны сортировка по возрастанию и убыванию, удаление повторов и пустых строк, обрезка крайних пробелов. Удаление повторов сохраняет первое точное вхождение. Сортировка учитывает числа в тексте, поэтому `item2` идёт перед `item10`. Одно **Ctrl+Z** отменяет всю операцию. **Ctrl+F** открывает поиск и замену в документе, **Ctrl+G** переходит к строке. На Mac используйте **⌘**.

Для CSV и TSV рядом с форматом появляется переключатель **Текст / Таблица**. Нажмите название столбца для сортировки, затем нажмите ещё раз для обратного порядка. Чтобы удалить дубликаты, отметьте столбцы для сравнения и нажмите кнопку удаления повторов. Если указать, например, город и дату, останется первая запись для каждой пары на момент операции. Остальные поля этой записи сохранятся вместе с ней.

Если файл начинается с данных, отключите заголовок первой строки. Редактор запоминает этот выбор для заметки. Кавычки, разделители и переводы строк внутри значений учитываются при разборе. Двойной щелчок по ячейке открывает её в исходном тексте. Сортировку и удаление повторов можно отменить прямо в таблице через **Ctrl+Z** или **⌘Z**.

**Ctrl+C** копирует полное значение выбранной ячейки, а **Ctrl+стрелка** переходит к краю строки или столбца. **Enter** открывает ячейку в исходном тексте. Во время сортировки или импорта **Esc** отменяет операцию и оставляет редактор открытым.

## Работа с картой

Нажмите **F1** на карте, чтобы посмотреть управление. Когда фокус на карте, **+** и **−** меняют масштаб, **0** возвращает 100%, а **F** умещает карту в окне. На macOS подсказки обозначают клавишу Command символом **⌘**.

В открытой заметке **Ctrl+S** (**⌘S** на Mac) сразу записывает текущие правки на устройство. Формулу можно сохранить, оставив курсор в поле ввода. Автосохранение продолжает работать, пока вы печатаете.

- Включите **Вид → Свободная расстановка**, чтобы скрыть линии связей и остановить автоматическое движение. Перетащите заметку или целое выделение в нужное место. Так можно перемещать и закреплённые заметки. Выключите режим, чтобы снова включить притяжение по существующим связям.
- Приблизьте заметку до 175%, чтобы прочитать её на карте. Стрелки в карточке перелистывают фрагменты, булавка запоминает выбранный, а щелчок по заголовку открывает редактор. Чтение приближением переключается в меню **Вид**.
- В **Маршрутах** создайте маршрут и щёлкайте заметки в порядке показа. В списке остановок можно поменять их порядок и выбрать фрагмент для каждой. Сохраните маршрут и нажмите кнопку воспроизведения. Клавиши **←** и **→** переключают остановки, **Esc** возвращает к исходному виду карты.
- В меню области выберите **Прогресс из таблицы…**, укажите ячейку и цель. Значение 7 при цели 10 закрасит 70% контура. В меню заметки пункт **График из таблицы…** связывает её с рядом чисел. Мини-график виден при наведении на заметку. Значения берутся из таблиц текущего пространства, в том числе из формул.
- Для канбана создайте область **Дорожка этапов** и дайте этапам названия. Двойной щелчок по свободному месту создаёт заметку на этом этапе. Перетащите одну или несколько заметок в соседний столбец, чтобы изменить этап. Группа занимает свободные места выбранного столбца. **Ctrl+Z** возвращает её на прежние места.
- Потяните за название этапа или свободный фон дорожки, чтобы переместить её вместе с заметками. **Shift** с протяжкой выделяет заметки рамкой. Кнопка с ползунками рядом с названием открывает настройки дорожки прямо на карте. Двойной щелчок по названию этапа сразу ставит курсор в поле его имени. **Ctrl+Z** отменяет перенос дорожки или сохранённое изменение её настроек.
- Чтобы поменять этапы местами, наведите курсор на название нужного этапа и потяните за появившуюся ручку из шести точек. На сенсорном экране сначала коснитесь названия. Линия между столбцами показывает место вставки. Отпустите ручку, и этап переместится со всеми заметками. Каждая сохранит свою строку. **Esc** отменяет жест, **Ctrl+Z** возвращает прежний порядок после переноса.
- Наведите курсор на стык соседних заголовков и нажмите **+**, чтобы вставить этап. Такие же кнопки есть по краям дорожки. Введите название и нажмите **Enter**. Чтобы убрать этап, щёлкните правой кнопкой по его названию и выберите **Удалить этап…**. Заметки можно перенести в другой этап или на карту рядом с дорожкой. При нехватке мест панель заранее показывает, сколько строк будет после переноса. **Ctrl+Z** отменяет вставку или возвращает удалённый этап с заметками в прежние ячейки.

- В левом верхнем углу карты нажмите **Новая заметка** для текста или **Новый холст** для свободного размещения объектов. Клавиши **Ctrl+N** и **Ctrl+Shift+N** создают их соответственно. Кнопка возврата в редакторе показывает, куда вы вернётесь — на карту, к списку, в область или к результатам поиска.
- Дважды нажмите на круг, чтобы открыть заметку. Перетаскивайте круги мышью. В контекстном меню круга есть команды закрепления и создания связи. Закреплённый круг сохраняет своё место под действием притяжения.
- Откройте **Внешний вид** через правый щелчок по заметке или кнопку с палитрой под выделенной заметкой. Можно задать форму, цвет и значок. Сброс цвета возвращает цвет области. Доступны 288 SVG-значков с поиском по русским и английским названиям. [Lucide](https://lucide.dev/license) и [Phosphor Duotone](https://github.com/phosphor-icons/core)
- Введите общий тег, например `#наблюдение`, в две заметки. Круги начнут притягиваться. Для ручной связи нажмите на инструмент с цепочкой и выберите два круга. В редакторе есть список связанных заметок и обратных ссылок.
- Обведите заметки рамкой или выберите их щелчками с **Ctrl** или **Shift**. Потяните любую из них в контур области на карте или на папку слева. При вложении подсветится самая глубокая область под указателем. Отпустите кнопку мыши, чтобы перенести всё выделение. **Esc** отменяет жест, **Ctrl+Z** возвращает всю группу на прежние места и в прежние области. Чтобы удалить выбранные заметки на карте или в списке, нажмите **Delete** и подтвердите. **Ctrl+Z** вернёт их вместе со связями.
- Чтобы создать область вокруг выделенных заметок, нажмите **В область…** и введите название. Пока вы тянете заметку, контур охватывает и её, и остальных участников области. Если переместить все её заметки вместе, за ними переместятся контур и подпись. Внутри области заметки притягиваются друг к другу с небольшим зазором. Соседние области мягко раздвигаются, а их контуры слегка сжимаются со стороны контакта. Вложенные области остаются внутри родительских. Закреплённые заметки и заметки на местах в сетке сохраняют свои координаты.
- Для ровных рядов нажмите **+** рядом с областями, выберите **Сетка**, задайте название и число столбцов и строк (от 1 до 100 по каждой стороне). Правый щелчок по карте позволяет создать сетку прямо в выбранном месте. Перетащите заметки на посадочную метку. Подсветка покажет все места, которые они займут, с учётом уже занятых. Связи сохраняются, заметки остаются на своих местах. За название можно передвинуть сетку целиком. Из списка области кнопка **Показать на карте** ведёт к её посадочным местам.
- Двойной щелчок по свободной ячейке создаёт в ней текстовую заметку, по занятой — открывает её. При переносе внутри обычной сетки на занятую ячейку две заметки меняются местами. Если перетянуть группу внутри сетки, она сохранит взаимное расположение, когда есть место. На дорожке можно обменять две заметки в пределах одного этапа. **Ctrl+Z** отменяет весь перенос.
- Чтобы удалить сетку или дорожку целиком, в режиме стрелки начните на свободном месте карты и обведите её рамкой. Когда подсветится весь контур, нажмите **Delete**. Можно также выбрать сетку щелчком по её названию или пустой ячейке. Заметки и связи останутся на карте. Если хотите удалить и заметки, выделите их новой рамкой и снова нажмите **Delete**. **Ctrl+Z** отменяет каждое удаление по очереди.
- Чтобы сблизить столбцы, потяните правый нижний угол сетки влево. Потяните вверх, чтобы сблизить строки, или по диагонали, чтобы изменить оба расстояния. Для точной настройки наведите указатель на сетку и нажмите кнопку у её названия. В разделе **Шаг сетки** отдельно задаются расстояния по горизонтали и вертикали от 24 до 320 единиц карты. **Esc** отменяет перетаскивание, **Ctrl+Z** возвращает прежние расстояния и положения заметок.
- Чтобы освободить ячейку, перетащите заметку за край сетки или дорожки и отпустите на свободном месте карты. Так можно вынести и несколько выделенных заметок. При извлечении из вложенной сетки заметки переходят в ближайшую родительскую область свободной формы, а при её отсутствии — на верхний уровень. **Esc** отменяет жест, **Ctrl+Z** возвращает заметки на их места. Для отдельной заметки также доступна команда **Извлечь из сетки**.
- Чтобы вложить область в другую, перетащите её за название на нужную папку. Подержите указатель над свёрнутой папкой, чтобы раскрыть её. Для переноса в корень отпустите над строкой **Верхний уровень**, для отмены нажмите **Esc**. Кнопка **…** у названия позволяет создать дочернюю область, переименовать или удалить папку. При удалении дочерние папки переходят на уровень выше. Заметки тоже поднимаются к родителю, а если родительская сетка заполнена, переходят выше по дереву. Все связи сохраняются.
- **Ctrl K** открывает поиск по заголовкам, тексту и тегам текущего пространства. Доступны фильтры области и закрепления, учёт регистра и регулярные выражения JavaScript. Совпадения подсвечиваются, **Enter** открывает результат. Слишком долгий запрос с регулярным выражением прерывается в отдельном потоке.
- Колесо мыши меняет масштаб. Клавиша **H** включает перемещение холста, **V** возвращает выбор, **F** помещает всю карту в окно. Правый щелчок на пустом месте позволяет создать заметку в этой точке.

На карте и в любом редакторе **Ctrl+Shift+F** открывает поиск по текущему пространству. В текстовом абзаце **Ctrl+K** вставляет ссылку. Для поиска можно также нажать лупу вверху редактора. Щелчок по результату или **Enter** прокручивает заметку к найденному фрагменту и ненадолго подсвечивает его. Переход работает в названиях, абзацах, блоках кода, заметках с данными и ячейках таблиц в заметках и на холстах. **К результатам** возвращает к тому же запросу, фильтрам и выбранной строке.

Поиск работает локально. Разблокируйте зашифрованную библиотеку или пространство в папке, чтобы искать по его заметкам. Заметки с собственным паролем исключены из общего поиска, даже когда открыты в редакторе. При блокировке пространства окно поиска закрывается.

После переноса или удаления заметки нажмите **Отменить** в уведомлении либо **Ctrl+Z** на карте или в списке. История каждого открытого пространства хранит до 20 последних переносов и удалений в порядке выполнения. Вместе с удалённой заметкой возвращаются её содержимое, оформление и связи в обе стороны.

## Списки и ссылки на папки

Чтобы разделить две части текстовой заметки, наберите `---` в отдельном абзаце и нажмите **Enter**. Появится горизонтальная линия, а курсор перейдёт под неё. Чтобы вставить линию в готовый текст, поставьте курсор в место разделения и выберите **Текст → Горизонтальная линия**. Чтобы убрать линию, щёлкните по ней и нажмите **Delete**.

Теги вроде `#projects` подсвечиваются при вводе. Нажмите на тег, чтобы открыть другую заметку с ним. Если совпадений несколько, выберите заметку из списка рядом с тегом.

В начале абзаца введите `-`, `*` или `+` и пробел, чтобы начать список с маркером **•**. Для нумерации введите `1.` или `1)` и пробел. **Enter** создаёт следующий пункт, **Tab** делает его подпунктом, **Shift+Tab** поднимает на уровень выше. **Enter** на пустом подпункте возвращает к родительскому списку, на верхнем уровне завершает список.

В текстовой заметке нажмите **Ссылка на папку** и выберите каталог. Если выделить слова заранее, они станут подписью ссылки. Также можно вставить полный путь через **Ctrl+K**. На холсте используйте **… → Ссылка на папку…**. Щелчок по ссылке открывает папку в файловом менеджере. На холсте ссылку можно перемещать мышью.

## Код и JSON в текстовой заметке

Вставьте JSON-объект или массив в пустой абзац. Редактор узнает его и подсветит ключи, строки, числа и логические значения. Нажмите **Форматировать JSON**, чтобы расставить переносы и отступы. Если в блоке JSON есть синтаксическая ошибка, команда покажет строку и столбец и поставит туда курсор.

Кнопка **Вставить блок кода** (`</>`) на панели создаёт блок на месте курсора или превращает выделенный фрагмент абзаца в код. Можно вставить и готовый фрагмент в тройных обратных кавычках с указанием языка. Язык подсветки выбирается в шапке блока. Там же есть кнопка копирования. **Ctrl+Enter** продолжает обычный текст под блоком. Поиск учитывает исходный код, а теги для карты извлекаются из заголовка и обычного содержимого заметки.

## Заметки-холсты и рисунки

Дважды щёлкните внутри прямоугольника, ромба или эллипса либо выделите фигуру и нажмите **Enter**, чтобы добавить или изменить подпись. Она останется в центре при перемещении и изменении размера фигуры.

На заметке-холсте выберите **Текст**. Щелчок создаёт текстовую область, а протяжка мышью задаёт начальный размер. Когда текст или вставленная картинка перестают помещаться, нижний край области опускается. Потяните за край, чтобы передвинуть область, или за угол, чтобы изменить её размер вручную.

Щёлкните по тексту, чтобы открыть над областью панель форматирования. Внутри доступны заголовки, списки и подпункты, ссылки, изображения и блоки кода. Для оформления самой области выделите её и откройте **Стиль объектов**. Фон и рамку можно настраивать по отдельности. Кнопка **Только текст** делает фон прозрачным и убирает рамку. Нажмите **Сохранить по умолчанию**, чтобы новые текстовые области на всех холстах проекта получали это оформление.

На холсте **Delete** удаляет выделенные объекты. При редактировании надписи он удаляет символы у курсора или выделенный фрагмент. Чтобы удалить надпись целиком, нажмите **Esc**, затем **Delete**. **Ctrl+Z** отменяет последнее действие, **Ctrl+Shift+Z** или **Ctrl+Y** повторяет его.

На заметке-холсте текст, картинки, линии и фигуры свободно располагаются на плоскости. В режиме выбора потяните за сам объект, чтобы переместить его. Так можно подхватить и текст. Одиночный щелчок по тексту ставит курсор, а двойной по пустому месту создаёт новую надпись. Во время набора мышью можно выделять символы. Вставляйте изображения из буфера обмена, из файла или перетаскиванием. Текст на холсте попадает в поиск, а хештеги связывают заметки на карте.

- Для выделения обведите объекты рамкой или добавьте их щелчками с **Shift**. Рамка слева направо выбирает только фигуры, попавшие внутрь целиком. Рамка справа налево захватывает и фигуры, которых касается. **Ctrl+G** собирает выделение в группу, **Ctrl+Shift+G** снимает один уровень группировки. Группы можно вкладывать друг в друга. Потяните за фигуру, чтобы переместить группу, за угловую точку, чтобы изменить её размер, или за ручку сверху, чтобы повернуть. **Shift** при повороте задаёт шаг 15°. **Ctrl+щелчок** выбирает один объект внутри группы.
- Кнопка с замком или **Ctrl+Shift+L** закрепляет выделенные объекты. Тем же способом их можно открепить. При перемещении направляющие помогают совместить центры и края. Чтобы временно отключить привязку, удерживайте **Ctrl** во время движения.
- Потяните за конец уже нарисованной линии или стрелки, чтобы переместить его. При приближении к фигуре появятся точки привязки. После перемещения или поворота фигуры конец линии следует за выбранной точкой. При перетаскивании середины отрезка линия или стрелка изгибается плавной дугой через указатель. Промежуточную точку можно снова передвинуть. Для существующей ломаной в панели стиля выберите **Углы → Скруглённые углы**. Прямую можно нарисовать одним протягиванием, ломаную — последовательными щелчками. Завершите ломаную двойным щелчком или клавишей **Enter**. **Alt+щелчок** по промежуточной точке удаляет изгиб. **Shift** ограничивает направление с шагом 15°.
- В панели стиля доступны точный, рисованный и эскизный контуры, варианты штриха, скругление углов, цвет и штриховка. Новые надписи используют рукописный Excalifont с кириллицей. Также доступны обычный и моноширинный шрифты. Перо учитывает нажим стилуса, при рисовании мышью толщина штриха меняется в зависимости от движения. Шрифт и движки рисования входят в приложение и работают офлайн. [Excalifont](https://github.com/excalidraw/excalidraw/tree/master/packages/excalidraw/fonts/Excalifont) · [Rough.js](https://github.com/rough-stuff/rough) · [perfect-freehand](https://github.com/steveruizok/perfect-freehand)

В текстовой заметке поставьте курсор между словами или абзацами и нажмите **Вставить рисунок**. На этом месте появится область с выбранным пером. Щелчок по существующей области показывает её инструменты и сразу позволяет выбрать объект. Потяните за правый нижний угол области, чтобы изменить её ширину и высоту. Когда угол в фокусе, размер можно менять стрелками. Щелчок по абзацу возвращает к тексту, а **Esc** выходит из области после завершения текущего действия. Изменения сохраняются автоматически. В области колесо прокручивает заметку, **Ctrl+колесо** меняет масштаб рисунка.

И в текстовой заметке, и на холсте кнопка **Область и связи** управляет боковой панелью. Приложение запоминает, открыта ли панель.

Меню **Файл** в панели рисунка позволяет открыть или сохранить файл `.excalidraw`. Поддерживаются прямоугольники, ромбы, эллипсы, линии, стрелки, штрихи от руки, текст и встроенные растровые изображения. При обмене сохраняются уровни группировки, состояние замка, привязки, нажим пера и идентификаторы шрифтов. Семейства шрифтов отображаются через доступные локальные начертания. Если файл содержит неподдерживаемый тип объекта, приложение показывает сообщение. [Формат файлов Excalidraw](https://docs.excalidraw.com/docs/codebase/json-schema)

## Плавающие таблицы

В текстовой заметке поставьте курсор в нужный абзац и нажмите **Вставить таблицу**. Таблица появляется в потоке текста, сразу можно печатать в A1. На заметке-холсте нажмите **Добавить таблицу**. Здесь таблицу можно свободно передвигать за название или захват и менять её размер угловым маркером.

Наведите указатель на таблицу. Щелчок по круглой ручке снизу добавляет строку, справа — столбец. Потяните ручку дальше, чтобы добавить сразу несколько. Для вставки в середину щёлкните правой кнопкой по номеру строки или букве столбца и выберите сторону вставки. Формулы и диапазоны графиков следуют за сдвинутыми ячейками.

Чтобы выбрать несколько строк или столбцов, протяните указатель по их номерам или буквам. Можно также щёлкнуть по первому заголовку, а затем с **Shift** по последнему. **Ctrl+щелчок** добавляет или снимает отдельную строку либо столбец. Нажмите **Delete** или выберите удаление в контекстном меню выделения. **Ctrl+Z** восстанавливает всю группу вместе с формулами. При выделении обычных ячеек **Delete** очищает их содержимое.

Если номера строк или буквы столбцов скрыты, выделите диапазон ячеек и щёлкните внутри него правой кнопкой. В меню можно удалить строки или столбцы, попавшие в диапазон. При удалении всех строк или всех столбцов таблица сохраняет одну пустую строку или один пустой столбец.

В меню **⋯** можно по отдельности скрыть название, номера строк и буквы столбцов. Там же можно отметить первую строку или первый столбец как заголовки. Чтобы отметить другую строку или столбец, откройте контекстное меню нужной ячейки.

Выберите ячейку и начните ввод. **Enter** подтверждает изменение, **Tab** переходит вправо и в конце строки переносит курсор в начало следующей. **Shift+Tab** идёт в обратном порядке. Диапазон можно выделить мышью или с **Shift**. Вставка одного скопированного значения заполняет всё выделение. У скопированной формулы пересчитываются относительные ссылки. Данные из нескольких ячеек вставляются по строкам и столбцам.

**Ctrl+стрелка** (**⌘+стрелка** на Mac) переходит к границе блока заполненных ячеек или через промежуток к следующему значению. Удерживайте ещё и **Shift**, чтобы расширить выделение.

Чтобы продолжить ряд, выделите исходные ячейки и потяните круглую точку в углу выделения. Например, числа `1` и `3` продолжатся как `5`, `7`, а даты `31.01.2024` и `29.02.2024` — как `31.03.2024`, `30.04.2024`. Одно число копируется, одна дата задаёт шаг в день. По трём значениям `2`, `4`, `8` таблица распознаёт удвоение. Работают также дни недели, названия месяцев и подписи вроде «Этап 01». В формулах смещаются относительные ссылки.

Можно тянуть вверх, вниз, влево и вправо. Если выделить несколько соседних столбцов данных и потянуть вниз, в каждом продолжится свой ряд. При выборе целых столбцов или строк точка появляется в их заголовке. Штриховка показывает будущие ячейки. Рядом с указателем видны адрес и значение крайней ячейки. Удерживайте **Ctrl**, чтобы повторять исходные значения по кругу. Для формулы копируется её вычисленный результат. Можно нажимать и отпускать **Ctrl** прямо во время протяжки. Если вывести точку за нижний или правый край таблицы, появятся дополнительные строки или столбцы. **Esc** отменяет протяжку, **Ctrl+Z** возвращает всю таблицу к состоянию перед заполнением.

Формула начинается со знака `=`. Щёлкните по ячейке или выделите диапазон, чтобы вставить ссылку. Ссылки в формуле и соответствующие ячейки подсвечиваются одним цветом. Можно выбирать ячейки из другой таблицы в той же заметке, в том числе под другим абзацем. Например, `=B2*C2` умножает количество на цену, `=SUM('Продажи'::D2:D8)` считает сумму по соседней таблице, а `=ROUND(AVERAGE(B2:B8);2)` округляет среднее до сотых. При переименовании таблицы ссылки обновляются.

Начните вводить имя функции, например `=s` или `=су`. Под строкой формулы появятся подходящие функции с описанием и синтаксисом. Чтобы посмотреть весь список, нажмите **Функции** или **Shift+F3**. Выберите вариант мышью или стрелками и нажмите **Tab** либо **Enter**. Внутри скобок последовательные щелчки по A1 и B1 дадут `=SUM(A1,B1)`, а протяжка от A1 до B1 вставит диапазон `A1:B1`. **Esc** закрывает подсказку.

Доступны семь функций — `SUM`, `AVERAGE`, `COUNT`, `MIN`, `MAX`, `ABS` и `ROUND`. Работают и русские имена, например `СУММ` и `СРЗНАЧ`. Для аргументов с десятичной запятой используйте точку с запятой, например `=ОКРУГЛ(1,45;1)`. Знак `$` фиксирует строку или столбец при копировании формулы. В одной таблице помещаются до 500 строк и 52 столбцов.

При выделении диапазона под таблицей появляются сумма, среднее и количество чисел. Щелчок по итогу вставляет формулу в свободную ячейку под диапазоном. Соседняя кнопка **Построить график** создаёт отдельный объект на холсте. Включите в выделение заголовки и подписи, чтобы они появились на графике. При наведении можно посмотреть точное значение и переключиться между линиями и столбцами. При изменении исходных чисел или формул график пересчитывается.

При экспорте в `.excalidraw` таблицы и графики видны как изображения. Файл также содержит формулы, содержимое ячеек и связи графиков, которые Videron восстанавливает при открытии.

## Содержимое и хранение

Документ заметки состоит из версионированных блоков. Текст поддерживает абзацы, заголовки, цитаты, отступы, начертания, цвет и гиперссылки. Изображения можно добавить из файла, буфера обмена или перетаскиванием. У каждой встроенной области сохраняются размер и редактируемое содержимое, включая фигуры, таблицы и графики.

В переключателе пространств выберите **Создать пространство…**. По умолчанию оно сохраняется в локальной библиотеке. Чтобы хранить его отдельно, выберите папку, в том числе папку облачного диска. Флажок **Зашифровать файл паролем** включает шифрование до первой записи. Существующее локальное пространство можно перенести через **Пространства на этом компьютере… → В папку…**.

В выбранной папке находятся документ `Videron.space` и служебный каталог `.videron-sync` с историей изменений. Для работы через облачный диск синхронизируйте **всю папку** на обоих компьютерах, включая скрытый каталог. На втором компьютере выберите **Открыть из папки…**. Для зашифрованного пространства потребуется тот же пароль. Шифрование такого пространства охватывает документ, вложения и историю. Ссылки на другие папки сохраняют свой путь.

Videron объединяет независимые правки заметок, в том числе после работы без сети. Если оба компьютера изменили одну заметку или один удалил её, пока другой редактировал, сравните **Этот компьютер** и **Общая копия**. Выбор **Позже** сохраняет обе версии. Кнопка **Сравнить версии** возвращает к выбору. Если изменение касается открытого редактора, его можно просмотреть, когда удобно закончить ввод. История хранится внутри пространства, повторяющиеся данные используются совместно.

**Свой сервер.** В меню **Пространство → Свой сервер…** введите адрес и пароль Videron Sync и выберите проект. Приложение запомнит проверенный адрес и само разместит рабочую копию. В **Проекты и папка…** можно перенести текущий проект в свою папку или создать пустой проект с отдельным названием. В версии 0.47 в этом же окне можно переименовать выбранный проект или удалить его с сервера для всех. После удаления скачанные рабочие копии доступны локально. Зелёная точка внизу боковой панели показывает действующее соединение. При возвращении сети клиент сверяет версии и догружает изменения. Для зашифрованного пространства нужен его пароль. Videron поддерживает прямое подключение и TCP через Cloudflare Tunnel. [Установка и подключение Videron Sync](server-setup.ru.md)

В Windows локальная библиотека обычно находится в `%APPDATA%\Videron\workspace.json`. Для пространства в отдельной папке в ней остаются название, путь и признак шифрования. Чтобы убрать рабочую копию из списка, откройте **Пространства на этом компьютере… → Убрать из списка**. Файлы останутся в папке. Флажок **Также удалить рабочую копию из этой папки** удаляет её заметки и историю с диска. Серверный проект при этом сохраняется.

Приложение записывает снимок во временный файл и заменяет им предыдущий после успешной записи. При штатном закрытии окна оно дожидается сохранения очереди изменений. Библиотеки с настраиваемыми пространствами используют версию схемы 3. Videron также читает прежние схемы 1 и 2. Объём файла и расход памяти растут вместе с объёмом изображений.

## Шифрование

**Отдельная заметка.** Откройте текстовую заметку или заметку-холст, нажмите замок в правом верхнем углу и дважды введите новый пароль. Правки сохраняются в зашифрованном виде даже при открытом редакторе. При следующем открытии заметка попросит пароль. Чтобы снять отдельное шифрование, нажмите замок ещё раз и введите текущий пароль.

В файл в зашифрованном виде попадают название, текст, поисковая копия, теги, код, рисунки, таблицы и вложения. На карте остаётся узел «Зашифрованная заметка». Положение, принадлежность к области, закрепление, ручные связи и служебные сведения о времени и открытиях остаются частью карты. Содержимое такой заметки исключается из общего поиска и данных расширений. Версии, сохранённые в незашифрованной папке до установки пароля на заметку, по-прежнему можно прочитать в истории папки, в том числе на сервере синхронизации, других устройствах и в резервных копиях. Чтобы защитить всю историю, включайте шифрование папки при создании пространства, до добавления заметок.

**Защита локальной библиотеки.** Внизу боковой панели выберите **Настройки → Шифрование библиотеки → Задать пароль**. Шифрование охватывает файл локальной библиотеки, включая её пространства, список подключённых папок и установленные расширения. При создании пространства в отдельной папке выберите **Зашифровать пространство** и задайте его пароль в той же форме. После разблокировки можно переключаться на другие пространства и возвращаться обратно. Videron снова попросит пароль при первом открытии этого пространства после блокировки или перезапуска приложения. Команда **Заблокировать сейчас** закрывает доступ и при работающем приложении. В настройках можно сменить или снять пароль библиотеки. Заметка с собственным паролем сохраняет его и внутри зашифрованного пространства.

**Автоблокировка.** В **Настройках → Автоблокировка** выберите интервал бездействия в Videron или укажите своё число минут. По умолчанию выбран режим **Только при новой сессии**. При блокировке Windows любой из этих режимов сразу скрывает открытое защищённое содержимое. Videron сохраняет последние правки и закрывает доступ к зашифрованному проекту и открытой заметке с собственным паролем. Чтобы вернуться к такой заметке, введите пароль проекта, затем пароль заметки. Если пароль установлен только на заметку, достаточно пароля заметки.

Выберите длинную уникальную парольную фразу и сохраните её в менеджере паролей. Для восстановления доступа понадобится пароль. Videron хранит зашифрованные данные с помощью AES-256-GCM, ключ выводит из пароля с помощью Argon2id (64 МиБ, три прохода, четыре потока). Каждая новая защита получает случайную соль, каждая запись — новый случайный nonce. Шифрование выполняет настольное приложение. Ранее сделанные резервные копии и отдельно экспортированные файлы сохраняют тот вид, в котором вы их записали. [Параметры Argon2id в RFC 9106](https://www.rfc-editor.org/rfc/rfc9106.html#section-4)

## Расширения

Откройте **Расширения → Спектр тегов** и выберите тег, чтобы увидеть связанные записи. Из этого списка можно перейти прямо в заметку.

Через это же окно можно импортировать собственное представление в виде JSON-файла. Например, следующий манифест выводит количество заметок в открытом пространстве. Сохраните его с расширением `.json` и выберите в окне импорта.

```json
{
  "apiVersion": 1,
  "id": "example.note-count",
  "name": "Количество заметок",
  "description": "Счётчик записей открытого пространства.",
  "html": "<style>body{font:18px system-ui;color:#ededed;background:#171717}</style><p id='value'></p><script>addEventListener('message', e => { if (e.source === parent && e.data.type === 'videron:data') document.getElementById('value').textContent = (e.data.language === 'en' ? 'Notes in this workspace: ' : 'Заметок в пространстве: ') + e.data.notes.length }); parent.postMessage({type:'videron:ready'}, '*')</script>"
}
```

Представление запускается в отдельном iframe с ограничениями sandbox и CSP. Встроенный «Спектр тегов» использует тот же API, что и импортированные представления.

| Сообщение | Направление | Содержимое |
| --- | --- | --- |
| `videron:ready` | Расширение → приложение | Запросить данные текущего пространства |
| `videron:data` | Приложение → расширение | `apiVersion`, текущий язык `language` (`ru` или `en`), массивы `notes` и `areas` |
| `videron:open-note` | Расширение → приложение | Открыть заметку с указанным `id` |

Объект заметки в API содержит `id`, `title`, `type` (`text`, `canvas` или `data`), `appearance` (форма, значок и цвет), `tags`, `areaId`, `pinned`, `opens`, `x`, `y`, `weight` и `links`. В `links` перечислены ручные связи. Связи по тегам можно восстановить из `tags`. Объект области содержит `id`, `name` и `color`. Этот API рассчитан на представления и навигацию.

## Сборка из исходников

Ядро написано на Go с Wails 2, интерфейс — на JavaScript с Canvas 2D. Сборка использует статические файлы из `frontend/` и встраивает их в исполняемый файл через Go embed.

```powershell
go run github.com/wailsapp/wails/v2/cmd/wails@v2.17.1 build -s -skipbindings -trimpath
```

Версия Go указана в `go.mod`. Команда предназначена для запуска из корня проекта. Для просмотра интерфейса в браузере можно выполнить `python -m http.server 8745 --bind 127.0.0.1 --directory frontend` и открыть `http://127.0.0.1:8745`. В таком режиме данные хранятся в localStorage этого браузера.

Проверки формул, графиков и формата рисунков запускаются командой `node --test` в Node.js 22 и новее.

Для самостоятельной сборки клиента под другую ОС установите компилятор и системный WebView для нужной платформы. [Инструкция Wails по настройке среды](https://v2.wails.io/docs/gettingstarted/installation/)
